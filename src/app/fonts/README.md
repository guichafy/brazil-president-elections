# Inter local

`inter-latin.woff2` é a variante variável (pesos 100–900) do subconjunto latino da fonte Inter, previamente servida por `next/font/google` neste projeto. Inclui os caracteres usados no português.

Origem: Google Fonts / [Inter](https://fonts.google.com/specimen/Inter), de Rasmus Andersson. Licença SIL Open Font License 1.1 em `OFL.txt`.

O arquivo está versionado para não exigir acesso ao Google durante o build.
